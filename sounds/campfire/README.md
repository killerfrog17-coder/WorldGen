Three locally generated, mono wood-fire loops. Delete a WAV you dislike; missing
takes are skipped when a world opens. Playback uses the Item effects volume and
is spatial around burning fires. Independent starting offsets avoid synchronized
crackles between fires. No preview UI or synthetic fallback.

Original prompts, models, seeds and output hashes: `assets/camp-audio/provenance.json`.
These are candidate recordings, not human listening-approved assets.
