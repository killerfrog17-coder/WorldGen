# Atlas visual overhaul - 18 October 2026

The shared read-only Presentation adapter provides typed table measurements,
numeric/string sorting, tab-specific dashboard selection, exact chart units,
illustrative appearance samples and deterministic NPC parameter queries. Neither
Unity nor JavaScript creates another historical simulation route. Complete article
text remains available in expandable context/definitions and Copy article.

| Tab | Main visual emphasis | Sortable directory data |
| --- | --- | --- |
| World | Population account comparison, habitat-patch presence, regional livelihoods, leading states and technological reach | Overview, not a fictitious entity table |
| States | Imperial hierarchy, diplomacy, forces, priorities, cities, research | Direct population/area, government, age, era, active/historical status |
| Provinces | Administrative relationships, local identity/language/religion, memory | District area, local government, administration type |
| Cities | Food support, demography, hinterland, crops and local political life | Residents, rural catchment, food-years, foundation, court, status |
| Peoples | Subsistence, local appearance, identity, language, knowledge, contacts | Population, area, way of life, stage, foundation |
| Ethnicities | Actual parent/branch links, social inheritance, regional appearance distributions and town examples | Recognition, origin, recorded cultural context, parent heritage |
| Languages | Sound/grammar facts, reusable phonetic word cards, related speech graph | Recognition, parent speech, script scaffold, word order |
| Religions | Doctrinal family, observance, independent teaching axes and institutions | Foundation, parent tradition, ethos and ritual |
| Ritual bodies | Public/lay affiliation, local support and institutional facts | Town, tradition, support, public/lay type |
| Technology | Separate research allocation/progress/deployment, levels, expandable prerequisites and project filters | Era, capabilities, represented culture population, active projects |
| Rulers | Recorded office, tenure and linked person/household records | State, accession, tenure, reputation, office status |
| Notable people | Actual dated achievements, family graph, aptitudes, offices and patronage | Age, roles, reputation, recent deed count, living/deceased |
| Organizations | Mandate, member-government graph, founding initiative and records | Member count, foundation, active/historical status |

Every category still opens an empty table if there are no records. Name/number/date
sorting has stable ID ties, missing values stay last, and filtering/paging retain
the selected ordering. Query work occurs on demand, not on a simulation turn.

Graphs link only actual recorded relationships. Word/root cards are not presented
as dated historical events. Composition strips are used only for real partitioned
accounts; independent doctrinal indices and overlapping language competence are
not forced to add to100%. No invented population curves or reconstructed past
data are created. Institutional access and court patronage are not mislabelled
as believer counts or individual technological access.

Both native IMGUI and browser articles use the same tab priorities, measurements
and chart semantics. The browser renders accessible clickable SVG relationship
nodes and portraits; Unity draws native equivalents. Expanded context preserves
method/source/limitations without filling every initial view with boilerplate.

The associated optional realm36 change fixes missing pre-cultural regional
heritage; see [its saved-state/NPC contract](HISTORY32_FORAGER_HERITAGE.md).
Appearance still consists of overlapping regional distributions, not one face
assigned to a social identity. Old saves receive the UI immediately but need an
explicit rules upgrade to start recording the new pre-cultural identities.
