# Political claim display

This is a presentation-only correction, not a historical rule change or a fix for missing geopolitical coverage. Frozen nativeAE29 era/performance evidence uses the preceding renderer; the separately rebuilt AF29 final-world camera evidence below verifies the new RGB distinction.

The measured example is final Earth29 at year158000/hash `aadce44b43b5823970e45c80d53ec9ebfb415294cf65893b8a032327606936e3`: the old native States image has a broad same-color Siberian/Indian extent, while the independent opaque actual-sovereign export leaves substantial interior land unowned. Those are different questions, not contradictory historical checkpoints. The external evidence is `native-ae29-earth-eras/10-Postmodern-map.png` versus `evidence-ae29-earth-final/political-identities/sovereigns.png` under the overnight artifact root. Neither old image demonstrates the new styling.

`HistoricalMapSnapshot.PoliticalSovereign` deliberately selects an actual sovereign first, then a recognized title holder where no actual controller exists. Previously both had the same full color and occupancy/selection code. States also colors by ruling culture, so the same hue never proves a single sovereign.

`ClaimOnly` identifies only the title fallback. Shared `SocietyView.OverlayColor(..., claimOnly)` desaturates and lightens its RGB in States/Civilizations. Actual control, all identities, selection, title profiles, borders, authoritative history, saves and hashes remain unchanged. Alpha is still an occupancy/selection data code, not transparency. The browser palette and Unity's tint cache use the same style; the Unity cache key includes claim-only status. No hatch shader or extra world census is introduced.

The existing selection card explains “Recognized claim only; no local state administration is recorded here.” Its bounded direct query reads the actual controller and title holder without constructing a cell-wide snapshot on the UI thread; tests compare it with the cached rendering classification. The expanded States/Civilizations legend reserves one short line, “Pale: recognized claims,” rather than relying on an unrendered hover tooltip or adding a map overlay box. Actual native legibility remains a rebuilt-player review requirement. A claim is not a finding that land is empty, that people consent, or that the title has uniform local control; full administrative color likewise is not a continuous shipping-service audit.

`HistoryClaimStyleTests.Run` checks a tiny administered/title-only/contested/unclaimed fixture, same-holder RGB distinction, actual-controller priority, unchanged nonpolitical overlays, matching browser/Unity shared RGB calls, unchanged prepopulated occupied/selected alpha bytes, existing selection identities, inspection notes, legacy no-title behavior and unchanged authoritative serialization/hash. This focused test does not itself execute `PrehistoryView.Codes` or compile the Unity caller. Execution and rebuilt-player visual review must be reported separately; source edits alone are not passing evidence.
