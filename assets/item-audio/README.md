# Tool/weapon Foley

Eighteen short mono PCM16 files generated locally with the already installed
Stable Audio 3 Medium/Small models, then trimmed, faded and gain-limited.
No purchased files, field recordings or runtime neural inference are required.
Complete selected prompts, model names, seeds, source/output hashes and crops
are in [provenance.json](provenance.json). Rejected trials stay in ignored artifacts.

The [official prompting guide](https://kb.stability.ai/knowledge-base/stable-audio-3-prompt-guide)
informs the source/action/recording prompts and states outputs can be distributed
and commercialized. Model execution uses Stability's [Community license](https://stability.ai/license)
for the current free local use; this is not a claim that model weights are CC0.
Weights/server are not shipped with the game. Checked 28 October 2026.

The candidates were checked with classifier diagnostics; the agent could not
listen to audio in this tool environment. Owner listening approval is pending.
Audio settings can preview each of three variants per category while in a world.
